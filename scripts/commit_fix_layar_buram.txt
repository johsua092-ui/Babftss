fix(scale-ui): bug layar buram setelah Konfirmasi ScaleNumberModal — tutup modal

MASALAH
Setelah klik Konfirmasi di modal ScaleNumberModal (Phase 74, commit
c455b03), layar user jadi buram (overlay blur 8px rgba(0,0,0,0.75)
tetap dirender) + tidak bisa interaksi apa pun lagi — seolah
terkunci. User terpaksa refresh halaman untuk keluar dari state ini.

PENYEBAB
Handler `handleScaleNumberConfirm(studs)` di BlockSimulator3D.jsx
TIDAK memanggil `setShowScaleNumberModal(false)` di akhir handler.
Akibatnya:
  1. User klik Konfirmasi → ScaleNumberModal.finishClose(callback)
     → setClosing(true) (animasi keluar 200ms mulai) + setTimeout.
  2. 200ms kemudian: callback() = handleScaleNumberConfirm(studs)
     → apply scale (obj.scale.setScalar) + toast.success.
  3. TAPI showScaleNumberModal di-caller MASIH true → React tidak
     unmount modal.
  4. Animasi keluar sudah selesai (modal opacity 0, transform
     scale 0.35), TAPI modal tetap di DOM dengan opacity 0.
  5. Overlay div (rgba(0,0,0,0.75) + backdropFilter blur 8px)
     TETAP menutupi layar → user lihat layar buram.
  6. zIndex overlay = 1100, di atas semua UI lain → user tidak
     bisa klik apapun.

Akar masalah: lupa panggil setter state `setShowScaleNumberModal-
(false)` di handler confirm. Bandingkan dengan handler
`handleScaleModeConfirm` (Phase 73, working tanpa bug) yang
memanggil `setShowScaleModeModal(false)` di akhir (baris 596).
Pattern yang sama LUPA diaplikasikan ke ScaleNumberModal karena
ScaleNumberModal adalah komponen baru Phase 74 yang tidak ikut
pattern yang sudah terbukti aman di ScaleModeModal.

SOLUSI
2 perubahan minimal di src/pages/BlockSimulator3D.jsx (handler
handleScaleNumberConfirm):

  1. Branch error (tidak ada block yang di-attach): tambah
     `setShowScaleNumberModal(false);` SEBELUM `return;`. User
     yang klik Konfirmasi tanpa pilih block dulu sekarang juga
     tidak stuck — modal tutup + toast.warning + user bisa klik
     block dulu lalu buka modal lagi lewat tombol +.

  2. Branch sukses (apply scale): tambah `setShowScaleNumberModal-
     (false);` SETELAH `obj.updateMatrixWorld();` SEBELUM
     `toast.success`. Modal tutup → overlay blur hilang → user
     bisa lanjut interaksi (lihat block yang baru di-scale, klik
     block lain, drag bola gizmo, dll).
