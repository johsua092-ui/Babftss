fix(scale-ui): varian picker ScaleModeModal tambah Batal/Konfirmasi + hapus X

MASALAH
Varian 'picker' (modal yang muncul saat klik tombol "+" di panel info
Scale) tidak punya tombol Batal & Konfirmasi — padahal varian
'onboarding' (muncul saat equip scale pertama) punya. Selain itu,
varian picker punya tombol "X" di header untuk tutup, padahal user
merasa tidak perlu karena sudah ada footer Batal/Konfirmasi yang
akan ditambahkan. User minta: TAMBAH tombol Batal & Konfirmasi ke
varian picker, HAPUS tombol X.

PENYEBAB
Phase 73 v2 (commit bc82b8c) membuat 2 varian dengan flow berbeda:
  - onboarding: pilih mode → Konfirmasi → apply (tidak bisa ditutup
    kecuali Batal/Konfirmasi)
  - picker     : klik mode → langsung apply + tutup modal (bisa
    ditutup lewat X / overlay / Escape)
Saat user minta tambah Batal/Konfirmasi ke picker, flow "klik mode
langsung apply" jadi inkonsisten — kalau klik kartu langsung apply
+ tutup, footer Batal/Konfirmasi tidak akan pernah diklik (modal
sudah tutup setelah klik kartu). Maka flow picker harus disamakan
dengan onboarding: klik kartu = setSelected (highlight), Konfirmasi
= apply, Batal = tutup tanpa apply.

SOLUSI
7 perubahan minimal di src/components/ScaleModeModal.jsx:
  1. Hapus `X` dari import lucide-react (line 2) — sudah tidak dipakai.
  2. Update text subtitle (baris 157-159): hapus kondisi isPicker,
     samakan untuk kedua varian: "Pilih aturan scaling, lalu klik
     Konfirmasi untuk menerapkan". Text lama versi picker "Klik
     salah satu mode untuk langsung memakainya" menyesatkan setelah
     flow diubah.
  3. Hapus block tombol X di header (26 baris, baris 161-188 lama).
  4. Hapus kondisi `isPicker ? 0 : 24` di marginBottom grid (baris
     176) → samakan ke 24. Sebelumnya, picker punya marginBottom 0
     karena footer tidak ada; sekarang footer selalu ada → harus 24

  5. Ubah onClick kartu mode (baris 183): hapus branch isPicker →
     hanya `setSelected(m)`. Klik kartu sekarang hanya highlight,
