  101. Default value modal = state yang user set sebelumnya,
      BUKAN current state target. Pola: `statePersist ?? default-
      Fallback`. Alasan: user buka modal untuk SET nilai baru,
      bukan lihat current value target yang berubah saat interaksi.
  102. Jangan asumsi batasan minimum input kalau user tidak
      eksplisit minta. Pakai 0 sebagai minimum default, KECUALI
      ada kontrak/app constraint hard (mis. MIN_ABS_SCALE app =
      0.05 di blockScale.js). Input modal = UX layer (fleksibel),
      apply layer = safety layer (hard clamp). Jangan campur aduk.
  103. Pola toggle: input 0 = matikan fitur, input > 0 = aktifkan
      dengan nilai itu. SATU kontrol untuk dua fungsi (toggle +
      value). Check `value > 0` di applyScaleByMode = toggle
      otomatis. Tambah toast beda untuk 0 vs > 0.
