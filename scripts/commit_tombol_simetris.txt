fix(scale-ui): tombol Batal & Konfirmasi ScaleModeModal simetris (flex:1)

MASALAH
Di modal "Scale Mode" (varian onboarding, muncul saat klik "+"), tombol
"Batal" (kiri) dan "Konfirmasi" (kanan) tidak simetris:
  - Batal: padding 10px 20px (lebar konten ~80px)
  - Konfirmasi: padding 10px 24px (lebar konten ~140px)
  - Container: justifyContent: 'flex-end' → keduanya di-push ke kanan
    sebagai satu grup, Batal menempel ke kiri Konfirmasi.
Hasil visual: Batal pendek, Konfirmasi panjang, grup di-kanan → tidak
simetris, terlihat tidak rapi. User minta: Batal dari kiri ke tengah,
Konfirmasi dari kanan ke tengah, sama rata panjang.

PENYEBAB
Tidak ada width/flex eksplisit di kedua tombol — lebarnya hanya ditentukan
oleh content + padding, jadi otomatis berbeda karena "Batal" (5 huruf)
vs "Konfirmasi" (9 huruf). Container justifyContent: 'flex-end' juga
meng-grup keduanya di kanan, bukan membagi rata 50:50.

SOLUSI
3 perubahan minimal (Aturan #5: ubah sekecil mungkin):
  1. Container: hapus `justifyContent: 'flex-end'` (jadi no-op ketika
     kedua anak punya flex:1 — biar tidak misleading dead context).
  2. Tombol Batal: tambah `flex: 1` di awal style.
  3. Tombol Konfirmasi: tambah `flex: 1` di awal style.
Efek: dengan flex:1 di kedua tombol + container flex dengan gap:12,
tiap tombol menempati (containerWidth - 12) / 2 = simetris 50:50.
Batal otomatis di kiri (sebagai anak flex pertama), Konfirmasi di
kanan. Padding berbeda (20px vs 24px) tidak memengaruhi lebar tombol
karena flex:1 men-stretch ke ukuran sama; padding hanya mengatur
posisi text dalam tombol.
