  "geser-geser". User Phase 83 kasih ide "pusat ikut titik tengah"

  benar sejak awal — user cuma perlu paham bahwa "pusat bergeser"
  = "pusat ikut titik tengah" (BUKAN "block pindah lokasi").

  per step (saat snap lompat antar step). Hysteresis band 0.6
  prevent lompat bolak-balik di boundary. Kalau user komplain
  "geser-geser" lagi, naikkan band ke 0.9.
