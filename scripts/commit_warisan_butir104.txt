  104. Bug goyang: snap + computeAnchorOffset = conflict. Saat
       snap lompat antar step, scale berubah cepat → offset
       berubah cepat → posisi goyang. Fix: skip computeAnchorOffset
       saat snap aktif. Trade-off: mode 1 side + snap = behavior
       2 side (scale dari pusat). Prioritas snap > sisi seberang
       diam.
  105. Input numerik: type="text" + inputMode="decimal" + manual
       onChange = kontrol penuh. type="number" punya locale issue
       (koma vs titik beda browser). type="text" + replace(",", ".")
       di onChange = koma→titik konsisten lintas-browser. Trade-off:
       hilang arrow ↑↓ bawaan type=number.
  106. Validasi maksimal N angka di belakang koma: pakai input
       string split('.')[1].length, BUKAN parsed number (parseFloat
       buang trailing zero: "1.500" → 1.5 → length 1 padahal user
       input 3 angka). Edge case: "1." → length 0 → valid (tapi
       parseFloat NaN → invalid lewat check lain). Penunjuk/hasil
       konversi boleh banyak angka — cuma INPUT yang dibatasi N.
