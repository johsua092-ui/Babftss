fix(scale-ui): Phase 76 — fix default value modal + izinkan input 0/0.01/0.02/dst

MASALAH
Dua keluhan user setelah Phase 75 (commit 6daaa3d):

1. Default value modal BERUBAH sesuai current scale block. User
   scale block jadi 8 studs panjang, lalu buka modal lagi untuk
   ganti step → default value di input = 8 (current scale block),
   BUKAN step saat ini. User expect: default value = step yang
   sedang aktif, BUKAN current scale block yang berubah-ubah.

2. Input 0.1, 0.2, 0.3, dst DILARANG (MIN_STUDS = 0.25). User
   mau bisa input mulai dari 0 (0 = no snap, drag bebas tanpa
   batasan) sampai 0.01, 0.02, ..., 0.1, 0.2, dst. Yang terkecil
   = 0 (snap dimatikan). Dari 0 → 0.01, 0.02, ..., 0.09, lalu 0.1,
   0.2, ... sesuai step yang user input.

PENYEBAB
1. handleComingSoonClick (Phase 74, commit c455b03) set default
   value = `Math.max(0.25, maxScale * STUDS_PER_BLOCK)` — yaitu
   current scale block dalam studs. Ini salah karena default value
   harusnya = step saat ini (yang user sudah set lewat Konfirmasi
   sebelumnya), bukan current scale block yang berubah saat user
   drag.

2. MIN_STUDS = 0.25 di ScaleNumberModal.jsx (Phase 74, commit
   c455b03) terlalu tinggi. User mau bisa input 0 (no snap) +
   nilai kecil seperti 0.01, 0.02, ... Saya set 0.25 karena takut
   block terlalu kecil sampai susah dilihat, tapi ternyata user
   mau fleksibilitas penuh.
