fix(scale-ui): Phase 75 — ubah ScaleNumberModal dari SET langsung ke STEP snap

MASALAH
Bug dari user: setelah set studs di ScaleNumberModal (Phase 74,
commit c455b03) + Konfirmasi, saat user drag bola gizmo scale,
block tidak "bertambah/berkurang per step studs" sesuai harapan.
User expect: input 2 studs → drag → block snap ke kelipatan 2
studs (1, 2, 3 block dst). Tapi aktual: drag bebas (smooth), tidak
ada snap. User coba 1, 0.5, 0.1 studs → juga tidak ada efek step
→ "matematikanya gimana??" — user kecewa.

PENYEBAB
Salah interpretasi saya di Phase 74. User sebenarnya minta:
input studs = STEP untuk drag bola gizmo (snap ke kelipatan),
BUKAN SET langsung scale ke nilai studs itu. Implementasi Phase 74
(commit c455b03) pakai pendekatan SET langsung (obj.scale.setScalar
(studs / STUDS_PER_BLOCK)) yang hanya apply 1x saat Konfirmasi,
tidak ada hook ke drag bola gizmo. Saat user drag setelah Konfirmasi,
Three.js TransformControls scale bebas tanpa ada snap → behavior
tidak sesuai harapan user.

Akar masalah: tidak baca ulang permintaan user Phase 74 dengan
teliti. User tulis: "jika user menginput scale number = 2 studs
maka jika user MENCOBA SCALE dia akan BERTAMBAH 2 block dan
BERKURANG 2 block". Kata "mencoba scale" = drag bola gizmo.
Kata "bertambah/berkurang per step" = snap. Saya salah baca sebagai
SET langsung (apply ke block saat Konfirmasi).

     delta = raw - startScale[a]

     >= 0.5*stepScale → block naik/turun 1 step. Snap HANYA
     sumbu yang di-scale oleh mode (axes dari getScaledAxes).
