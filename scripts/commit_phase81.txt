CATATAN
- BUG INI = lesson learned lanjutan dari kontrak butir 113 (salah
  interpretasi permintaan user). Phase 80 saya implementasi
  handleScaleNumberCancel untuk set default 2 saat user Batal
  modal ScaleNumberModal. TAPI user Phase 81 tidak pernah buka
  modal ScaleNumberModal → state tetap null → snap tidak aktif.
  Saya Phase 80 salah paham: kira user mau "default 2 SETELAH
  Konfirmasi/Batal modal ScaleNumberModal". Ternyata user mau
  "default 2 SEJAK AWAL, bahkan sebelum user buka modal".
- Pelajaran: kalau user bilang "default X", cek APAKAH default
  itu berlaku sejak awal (state initial) atau SETELAH user
  interaksi tertentu (Konfirmasi/Batal modal). Kalau user tidak
  specify, TANYA. Atau implementasi default sejak awal (lebih
  safe, karena covers semua case). Phase 81 = default sejak awal.
- Trade-off: dengan default 2, snap aktif sejak awal. User tidak
  bisa "no snap" (smooth drag) kecuali buka modal + input 0 +
  Konfirmasi. Acceptable karena user Phase 76/77 bilang "0 = no
  snap" (user tahu cara matikan snap).
