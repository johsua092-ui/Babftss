fix(scale-ui): hapus badge "bawaan" di mode 2 Side ScaleModeModal

MASALAH
Di modal "Scale Mode" (tombol "+" di tools Scale), kartu mode "2 Side"
menampilkan badge teks "bawaan" di sudut kanan-kartu. User minta
teks ini dihapus karena tidak perlu ada di sana — terlihat berisik
dan tidak memberi informasi tambahan bagi user.

PENYEBAB
Block JSX kondisional {m === '2side' && (<span>bawaan</span>)} ada
di src/components/ScaleModeModal.jsx baris 238-244. Tidak ada
referensi/fungsi lain yang membaca badge ini — hanya render visual.
Diverifikasi lewat:
  rg "bawaan" src/ -n → hanya 1 match di ScaleModeModal.jsx:243
  rg "'2side'" src/ -n → match lain semua untuk LOGIKA, bukan badge
Tidak ada test file untuk ScaleModeModal.jsx (find -name "*ScaleModeModal*"
hanya menemukan file komponennya sendiri).

SOLUSI
Hapus seluruh block JSX badge bawaan (7 baris, baris 238-244):
  {m === '2side' && (
    <span style={{...}}>bawaan</span>
  )}
Sebelum: label "2 Side" + badge "bawaan" (marginLeft auto push kanan)
         + checkmark aktif (marginLeft 6, menempel ke badge bawaan)
Sesudah: label "2 Side" + checkmark aktif saja.
Efek samping kecil (TIDAK di-fix, sesuai instruksi user "jangan
menyenggol yang lain"): baris 247 masih punya
  marginLeft: m === '2side' ? 6 : 'auto'
jadi saat mode 2side aktif, checkmark akan menempel ke label (marginLeft
6px) — bukan ter-push ke kanan seperti mode 1side/4side/6side.
Sengaja dibiarkan apa adanya: user eksplisit melarang menyenggol kode
lain; efek visual bisa di-review terpisah kalau user komplain.
