       saat drag (feedback instant), BUKAN delayed ke mouseUp.
       Pola: snap harus real-time saat drag. Kalau goyang, fix
       dengan hysteresis (BUKAN pindah snap ke mouseUp).
  111. Hysteresis band 0.6 = fix goyang di boundary + snap
       real-time + sisi seberang diam. Implementasi: track
       lastStep per-sumbu di obj.userData.__snapLastStep. Reset
       di drag mulai + clear di drag selesai. Band 0.6 (lebih
       besar dari Math.round 0.5) prevent lompat bolak-balik di
       boundary. Trade-off: block lambat (perlu drag 0.6×stepScale
       untuk pindah step). Acceptable untuk snap.
  112. Default scale mode BISA BERUBAH antar phase — user pref
       mutable. Phase 73 = 1side, Phase 79 = 2side. Jangan asumsi
       default dari Phase X tetap valid forever.
