feat(scale-ui): Phase 74 — modal ScaleNumberModal untuk input scale dalam studs

MASALAH
Tombol "+" di GizmoBlockInfoPanel (Phase 73 v3, commit e4bd4ce)
sebelumnya = "coming soon" (toast.info). User minta sekarang
tombol "+" BUKAN lagi coming soon — harus membuka jendela
peringatan oranye SAMA PERSIS designnya dengan modal Scale Mode
(Phase 73, modal yang dipakai tombol gear). Tapi body modal ini
BUKAN pilih 4 mode, melainkan INPUT nilai scale dalam satuan
STUDS. Apply nilai studs ke block yang sedang di-attach ke gizmo
(tc.object).

PENYEBAB
User ingin fitur input scale number eksplisit (bukan cuma drag
bola gizmo) supaya bisa set nilai presisi. Fondasi matematika
sudah ada sejak Phase 72 (2026-09-15) di src/utils/blockStuds.js
+ test_blockStuds.mjs (11/11 PASS): STUDS_PER_BLOCK = 2 MUTLAK,
formula studs = 2 × |scale|, inverse scale = studs / 2. Tapi
belum pernah dipakai untuk INPUT USER sampai Phase 74 ini.

  0.05 = 0.1 studs). MIN_STUDS ScaleNumberModal = 0.25 lebih
  besar dari 0.1 studs (MIN_ABS_SCALE app), jadi tidak konflik
  dengan clamp app. Kalau user input 0.25, app tetap clamp ke
  0.05 minimum abs scale (sudah diatur di blockScale.js /
  gizmoScaleBalls.js — tidak disentuh di commit ini).
