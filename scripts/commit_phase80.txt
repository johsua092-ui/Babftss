MASALAH

saya kira = scale mode 2side. Ternyata user maksud = SCALE NUMBER
(input studs) default 2. User Phase 80 klarifikasi:

"sepertinya anda salah paham yang saya maksud itu default '2'
adalah 'scale number' jadi scale number default '2' jika user
memilih konfirmasi atau memilih batal tanpa mengatur scale number
terlebih dahulu, dan sekarang tolong ubah mode default kepada
1 side ya!"

→ '2side' karena salah interpretasi. User sebenarnya mau:
