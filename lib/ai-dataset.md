## Game Info & Sejarah

### Deskripsi
- **EN:** Build A Boat For Treasure is a Roblox game where players build boats from blocks to navigate a river full of obstacles to reach treasure.
- **ID:** Build A Boat For Treasure adalah game Roblox di mana pemain merakit kapal dari berbagai balok untuk mengarungi sungai penuh rintangan demi harta karun.

### Developer
- **EN:** Created by **chillthrill709** under **Chillz Studios**, released 2016.
- **ID:** Dibuat oleh **chillthrill709** di bawah **Chillz Studios**, rilis 2016.

### Konsep
- **EN:** Sandbox / Survival / Physics — creative building + physics-based survival.
- **ID:** Sandbox / Survival / Fisika — kreativitas merakit + bertahan hidup berbasis fisika.

### Tujuan
- **EN:** Reach "The End" waterfall → open treasure chest → get Gold + Gold Blocks.
- **ID:** Capai air terjun "The End" → buka peti harta karun → dapat Gold + Gold Block.

### Mekanik
- **EN:** Special Tools for adjusting block physics properties (collision, transparency, scaling, binding buttons/levers to thrusters/motors).
- **ID:** Tools khusus untuk mengatur properti fisik balok (kolisi, transparansi, scaling, binding tombol/tuas ke pendorong/motor).
